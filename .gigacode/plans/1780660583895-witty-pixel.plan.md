# План проверки доступности удаленного сервера 192.168.0.120

## Цель
Проверить доступность входа на удаленный сервер 192.168.0.120 по логину `eljah` и паролю `Tatarstan1920`.

## Подход

### PowerShell скрипт

Использовать встроенные в Windows средства для проверки SSH-подключения:
1. Проверить доступность порта 22 через `Test-NetConnection`
2. Попытаться установить SSH-сессию с использованием `ssh` (если OpenSSH установлен)

## Детали реализации

### Подход: PowerShell скрипт

Создать скрипт `bin/check-remote-server.ps1`, который будет:
1. **Проверять доступность порта 22** через `Test-NetConnection -Port 22`
2. **Проверять аутентификацию** через `ssh eljah@192.168.0.120` с использованием переданного пароля
3. **Обрабатывать различные случаи**: недоступный хост, закрытый порт, ошибки аутентификации, таймауты

## Как использовать
```powershell
# Запуск скрипта
bin\check-remote-server.ps1
```

Скрипт будет последовательно проверять:
1. Доступность хоста через TCP порт 22
2. Возможность установить SSH-сессию с указанными учетными данными
3. Выводить понятное сообщение о результате

## Ожидаемый результат
Сообщение о том, доступен ли сервер, работает ли SSH-порт 22, и правильно ли работают учетные данные.
